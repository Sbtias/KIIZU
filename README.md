# KIIZU

Plataforma web moderna de minijuegos multijugador con Supabase.

## Stack
- HTML5, CSS3, JavaScript moderno
- Supabase Auth, Postgres y Realtime
- Arquitectura modular

## Estado
Base inicial del proyecto. La configuración de Supabase se realiza mediante variables de entorno o el archivo de configuración local; nunca se debe subir una service role key.
